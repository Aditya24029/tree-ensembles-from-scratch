# Data

The datasets aren't included in this repo. You need:

```
data/mnist.npz                  # MNIST (x_train, y_train, x_test, y_test)
data/fashion-mnist_train.csv    # Fashion-MNIST, label in the first column
data/fashion-mnist_test.csv
```

- `mnist.npz`: https://storage.googleapis.com/tensorflow/tf-keras-datasets/mnist.npz
- Fashion-MNIST CSVs: Kaggle, "zalando-research/fashionmnist"
